# Web App 最下方新增一条状态栏

- **Date:** 2026-10-22
- **Type:** feat
- **Scope:** `web`, `server`
- **PR:** [#1286](https://github.com/Prism-Shadow/penguin-harness/pull/1286)

[English](2026-10-22-webui-bottom-status-bar.md)

Web App 的外壳如今收在一条状态栏里。左侧读服务器所在的机器——整机 CPU 利用率与已用/总内存，
再无其他（不含磁盘）；每 10 秒一次请求刷新，标签页隐藏时暂停。右侧标出当前打开的 company 与
你所在会话的 workdir，然后是整个 harness 的会话计数 `session: ${running} / ${all}`：覆盖
harness 持有的全部 Project、全部来源客户端，而不只是侧栏列出的那个 Project。

## 细节

- 一次轮询（`GET /api/harness-status`，仅管理员——非管理员收到 403，状态栏永不渲染）带齐
  状态栏重绘所需的一切：计数、最新的 100 个会话及其运行状态、机器的 CPU 与内存。
- CPU 利用率是服务端按需取两次 `os.cpus()` 读数的比值；进程首次读取返回 null，状态栏显示
  占位文案；两次读取间隔不足 2 秒时直接回缓存答案——无后台定时器，无密集轮询。
- `all` 计 harness 持有的全部会话，减去本浏览器从列表移除的那些：点行上的 x 即从列表移除，
  计数随之减一。移除只是浏览器侧的记账——会话本身不受影响。
- 你打开过的会话，若某次轮询首次读到它由运行转为空闲，会带上一次性的「已空闲」标记，
  直到你再次打开它。
- 点击计数打开列表：行可跳转到该会话，行上的 x 将其移除；比最新 100 个更早的会话在列表
  底部以计数概括。
- 本轮状态栏是 Web App 布局的固定部分；接缝只有一个组件，以后可以换成插件提供。
