# 首页改为一句标语加两个回放演示

- **Date:** 2026-10-25
- **Type:** feature
- **Scope:** `landing`

[English](2026-10-25-landing-story.md)

落地页首页围绕一条主线重新编排：先是标语首屏，再是 A2APP 与可观测的自进化两个演示，其后依次为成本对比、客户案例、最新动态、快速开始与结尾。

## 细节

- **首屏。** 标语「让软件持续成长，让进化触手可及」（"Software that keeps growing. Evolution within reach."）和副标题「免费、稳定的 Agent 自进化框架」（"A free, stable RSI framework for agents"）取代了原来的定位语、角标、标语行、三块数据卡片和以数量开头的目录行。供应商标志一行末尾是「等 1000+ 个模型」链接，按站点语言打开 MMSP 的模型索引；其下仍是开始页的实时演示。页面标题、描述、分享卡片和页脚标语随之更新。
- **A2APP。** 脚本化播放器为开始页的每个起步示例各回放一次运行（合同工作台、文档问答、行情看板）：一句话生成工作台，加载后它的标签页出现在「聊天」旁边，工作台经宿主接口调用 Agent；合同工作台那一次还会在聊天里再说一句，加上一列、标签页热重载，「历史」里多出一个版本。其后是法务应用的实录视频及其花费，以及指向《从 A2UI 到 A2APP》的链接。这一节取代了原来的案例区；页脚的 `/#cases` 链接改为 `/#a2app`，并新增 `/#self-evolution`。
- **自进化。** 脚本化播放器回放默认循环的两轮，旁边的记分板只在版本保留时增加一个点（第 2 轮被回滚）；其后是自进化算法与评估集两行目录、决策智能体实录视频及其花费，以及文档链接。
- **移除。** 三个展示块、带示意趋势的循环图、架构放射图和与 Agent 开发库的对比离开了首页。两段实录视频下不再有复述视频内容的句子。
- 两个播放器都标注「示例运行」，离开视口即暂停；系统设置减少动态效果时只显示完成态，不播放。
