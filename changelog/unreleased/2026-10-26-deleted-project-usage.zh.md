# 防止已删除项目的用量记录重新出现

- **Date:** 2026-10-26
- **Type:** fix
- **Scope:** `server`
- **PR:** [#1364](https://github.com/Prism-Shadow/penguin-harness/pull/1364)

[English](2026-10-26-deleted-project-usage.md)

删除项目会清空其用量历史，但超过清理等待上限后才结束的请求，过去仍可能为该项目插入新记录。
用量记录器现在会在保存已报告的 token 或失败请求记录之前检查项目是否仍存在。
此检查适用于主会话、子代理记录和自动标题等独立用量。

使用相同 ID 重新创建项目后，旧项目的迟到用量也会丢弃，新项目自身的请求用量仍正常记录。

只删除会话、保留项目时，仍会保存已报告的用量。本次改动不调整删除等待上限，也不估算服务商扣款。
